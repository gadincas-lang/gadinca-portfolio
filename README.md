# Gadinca Portfolio

Portfolio profesional de Ing. Gad Josue Inca Saavedra — Ingeniería Civil, Bolivia.

## Stack

- HTML5 + CSS inline + vanilla JavaScript
- Assets optimizados: imágenes en WebP, videos MP4 con lazy loading
- Sin dependencias de build — deploy directo

## Deploy

Este sitio está desplegado en **Cloudflare Pages** con despliegue automático desde la rama `main`.

URL de producción: https://gadinca.com

## Estructura

```
├── index.html       # Página principal (sitio completo en un archivo)
├── sitemap.xml      # Sitemap para SEO
├── assets/          # Imágenes WebP y videos MP4
└── README.md
```
